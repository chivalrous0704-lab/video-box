# 動画BOX v0.19

## 修正内容
Instagram動画がMP4として保存できてもiPhoneで再生できない問題への対策版です。

v0.18までの「MP4整形」だけでは直らなかったため、
Instagramだけは取得後に実際にiPhone互換形式へ変換します。

変換内容:
- H.264
- AAC
- yuv420p
- 最大720p
- 30fps
- ultrafast
- faststart

Renderの無料環境でも終わりやすいように、画質を抑えて高速変換します。
変換は最大60秒、画面側は最大75秒でタイムアウトします。

TikTokなどは従来の軽い処理のままです。
